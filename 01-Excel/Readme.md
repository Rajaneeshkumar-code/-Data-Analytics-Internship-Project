# 📊 Excel — Data Analytics Internship Project

This folder contains the Excel work completed as part of my **Data Analytics Internship**. It covers core Excel skills used in real-world data analysis, including automation with VBA, data summarization with Pivot Tables, data transformation with Power Query, and dashboard creation for reporting.

🔗 Part of the main repository: [Data-Analytics-Internship-Project](https://github.com/Rajaneeshkumar-code/-Data-Analytics-Internship-Project)

---

## 📁 Files in this Folder

| File | Description |
|------|-------------|
| `Macro_VBA_IN_Excel.xlsm` | Excel workbook demonstrating **VBA macros** for task automation (e.g., automating repetitive actions, custom functions, and workflow efficiency). |
| `Pivot Table.xlsx` | Workbook showcasing **Pivot Table** creation to summarize, group, and analyze large datasets quickly. |
| `Power query.xlsx` | Workbook demonstrating **Power Query** usage for importing, cleaning, and transforming raw data before analysis. |
| `Sale_Dashboard_Excel.xlsx` | An interactive **sales dashboard** built using charts, formulas, and formatting to visualize key business metrics. |

---

## 🛠️ Topics Covered

- **VBA / Macros**
  - Recording and writing macros
  - Automating repetitive tasks
  - Basic VBA scripting for Excel automation

- **Pivot Tables**
  - Summarizing large datasets
  - Grouping and filtering data
  - Creating quick insights with rows, columns, and value fields

- **Power Query**
  - Importing data from multiple sources
  - Cleaning and transforming raw/messy data
  - Merging and appending queries

- **Excel Dashboard**
  - Building interactive sales dashboards
  - Using charts, slicers, and conditional formatting
  - Designing dashboards for clear business reporting

- Automating repetitive Excel tasks using VBA to improve efficiency
- Using Pivot Tables to turn raw data into meaningful summaries
- Cleaning and transforming datasets with Power Query before analysis
