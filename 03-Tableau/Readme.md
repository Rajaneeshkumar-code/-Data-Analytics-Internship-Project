# 03 - Tableau

This folder contains my Tableau learning and practice work as part of the **Data Analytics Internship Project**. It includes practice workbooks, reference material on Tableau functions, and the datasets used to build the visualizations.

## Contents

| File | Description |
|---|---|
| `12_days_Practise.twb` | Tableau workbook with daily practice exercises covering core charting and analysis techniques over a 12-day learning plan. |
| `Praticece13.twb` | Additional Tableau practice workbook (Day 13), building on the concepts from the earlier practice sessions. |
| `BI Tools - Tableu Functions.pdf` | Reference document summarizing key Tableau functions, calculations, and BI concepts used while building the workbooks. |
| `BI Tools - Tableu.xmind` | Mind map (XMind file) organizing Tableau/BI tool concepts, features, and notes for quick revision. |
| `Dataset.xlsx` | Primary dataset used for the Tableau practice exercises and visualizations. |
| `D3.csv` | Supplementary CSV dataset used for additional charts/analysis. |

## What This Covers

- Building and formatting charts (bar, line, pie, maps, etc.) in Tableau
- Using calculated fields, filters, and parameters
- Working with different data sources (`.xlsx`, `.csv`) inside Tableau
- Organizing and documenting BI tool concepts for reference

## How to View

1. **Tableau Workbooks (`.twb`)** — Open with [Tableau Desktop](https://www.tableau.com/products/desktop) or [Tableau Public](https://public.tableau.com/) (free). Note: `.twb` files reference external data sources, so keep `Dataset.xlsx` and `D3.csv` in the same folder (or reconnect the data source if prompted).
2. **PDF Reference** — Open `BI Tools - Tableu Functions.pdf` with any PDF viewer.
3. **Mind Map** — Open `BI Tools - Tableu.xmind` with [XMind](https://xmind.app/) (free) to view the concept map.
4. **Datasets** — `Dataset.xlsx` can be opened in Excel/Google Sheets; `D3.csv` can be opened in any spreadsheet tool or text editor.
