# 02 - Statistics

This folder is part of the [Data Analytics Internship Project](https://github.com/Rajaneeshkumar-code/-Data-Analytics-Internship-Project) and contains notes, notebooks, and reference material covering core statistics concepts used in data analytics.

## 📂 Contents

| File | Description |
|------|--------------|
| `6_DA_ExploringMeanMedianQuartile.ipynb` | Notebook exploring measures of central tendency — mean, median, mode — and quartiles. |
| `7_Permutation&Combination.ipynb` | Notebook covering permutation and combination concepts with examples. |
| `9_DA_ProbabilityDistribution.ipynb` | Notebook exploring probability distributions and their properties. |
| `Population_Sampling.ipynb` | Notebook demonstrating population vs. sampling concepts and techniques. |
| `Code Explanation.docx` | Written explanation of the code used across the notebooks in this folder. |
| `Steps_population&Sample.docx` | Step-by-step notes on population and sampling methodology. |
| `DAY_7.pptx` | Presentation slides covering Day 7 topics (Permutation & Combination). |
| `Population & Sampling.pdf` | Reference/notes document on population and sampling. |
| `Probability Distribution.pdf` | Reference/notes document on probability distributions. |
| `Statistics.pdf` | General statistics reference notes. |

## 📌 Topics Covered

- Measures of central tendency (Mean, Median, Mode) and Quartiles
- Permutations and Combinations
- Population vs. Sample, and Sampling techniques
- Probability Distributions
